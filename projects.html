Fantasy Sports Probability Calculator

Python

A Python application to analyze historical sports data and generate probabilistic performance predictions for fantasy sports leagues.

Python Statistics Data Analysis
View Details

Overview

This project analyzes historical fantasy sports data to calculate probability distributions for player performance. Using statistical models and historical trends, it helps fantasy sports enthusiasts make data-driven decisions when drafting players or setting lineups.

Key Features

  • Analyzes historical player performance data across multiple seasons
  • Applies statistical models to forecast outcomes and scoring trends
  • Generates probability distributions for player point projections
  • Supports multiple fantasy sports formats (PPR, Standard, etc.)
  • Outputs visual reports and exportable predictions

How It Was Made

Built using Python with pandas for data manipulation and scipy/numpy for statistical analysis. The application cleans and normalizes historical data, then applies regression analysis and probability distributions to generate predictions. Matplotlib provides data visualization capabilities.

Technologies Used

Python pandas NumPy SciPy Matplotlib

Fitness Tracker iOS & Web App

Swift / React

A native iOS application and React web app to track workouts, caloric intake, and fitness progress with REST APIs and persistent storage.

Swift iOS React
View Details

Overview

A comprehensive fitness tracking application available as both a native iOS app and a React web application. The app helps users monitor their workouts, track caloric intake, and visualize their fitness progress over time with analytics and goal tracking features.

Key Features

  • Native iOS app built with Swift and SwiftUI
  • Track workouts with detailed exercise logging (sets, reps, weight)
  • Monitor caloric intake and nutritional macros
  • Visualize fitness progress with interactive charts
  • Set and track personal fitness goals
  • REST API integration for cross-platform data sync
  • Responsive web version for desktop access

iOS Development

The iOS application was built using Swift with SwiftUI for the user interface. Leveraged Apple's HealthKit for health data integration, Core Data for local persistence, and implemented smooth animations using SwiftUI's animation framework. The app follows Apple's Human Interface Guidelines for a native iOS experience.

Web Development

The web version was developed using React with TypeScript for type-safe code. Implemented REST APIs for CRUD operations on workout and nutrition data. Used component-based architecture for reusability and state management for real-time UI updates. Chart.js provides interactive data visualization.

Technologies Used

Swift SwiftUI iOS HealthKit Core Data React TypeScript REST APIs Chart.js

Gyroscope-Controlled Sports & Stock Ticker

Embedded Systems

An embedded system controlled via gyroscopic input to navigate real-time sports and financial data on an LED matrix display.

Python Hardware APIs
View Details

Overview

An innovative embedded system project that uses gyroscopic sensor input for hands-free navigation between real-time sports scores and stock market data. The data is displayed on a custom LED matrix with optimized low-latency updates.

Key Features

  • Gyroscope-based navigation for hands-free control
  • Real-time sports scores from live APIs
  • Live stock market and financial data display
  • Custom LED matrix output with optimized rendering
  • Low-latency data polling and display updates
  • Modular architecture for easy customization

How It Was Made

Designed and implemented using Python with hardware integration libraries. The gyroscope sensor input is processed to navigate between data views. Live APIs are polled at optimized intervals to fetch sports and financial data, which is rendered on the LED matrix. Built with attention to latency optimization and power management.

Technologies Used

Python Embedded Systems REST APIs Gyroscope Sensor LED Matrix
